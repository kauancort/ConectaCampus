# Changelog

## v0.1.0-mvp — 2026-11-05 (versão sugerida, sem tag Git)

- Base ASP.NET Core Minimal API com Identity, JWT, EF Core e MySQL em Docker.
- Cadastro, login, catálogo/filtros, publicação, edição/cancelamento de atividades, inscrições e consulta privada de participantes.
- Protótipo web React + TypeScript integrado à API.
- Documentação de execução, validação reduzida e piloto proposto.
- Sem deploy externo. RF09/presença, RF10/avaliações, MongoDB Atlas e métricas Python/Pandas não foram implementados.

## Empacotamento ConectaCampus — 2026-11-06

- Frontend, API ASP.NET Core e MySQL configurados para execução local com Docker Compose; volume MySQL existente preservado.
- Mensagens de erro apresentadas pela API e interface em português; idioma da interface definido como pt-BR.
- Documentação de envio identifica Kauan Cortiço como responsável pelo envio.
